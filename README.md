> *Ookini* es una tienda virtual dedicada al café de especialidad, donde cada taza cuenta una historia. Proyecto frontend en desarrollo activo.

## 🚀 Instalación y uso local

No se requieren dependencias ni herramientas adicionales. Sigue estos pasos:

1. **Clona el repositorio**
```bash
    git clone https://github.com/tu-usuario/ookini.git
```

2. **Entra al directorio**
```bash
   cd ookini
```

3. **Abre el proyecto**
   Abre el archivo `index.html` directamente en tu navegador, o usa una extensión como [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) en VS Code para una mejor experiencia de desarrollo.
